# Seat and mirror trials

Real independent seat loading is available through the shared card/panel/child-lock controller when enabled in Settings. It uses typed Float feedback and native momentary commands, not absolute percentage setters or native memory slots. Legacy captures need recording again. Mirror coordinates remain references in saved presets. Only explicit confirmed mirror trials may send a tilt command.

Developer tools > Seat trials is an optional check before loading. Choose Backrest, Fore/aft, Height or one left/right mirror axis. Read seat and mirror positions. Choose Forward/up or Back/down for a nominal 100/200/300 ms seat request; mirrors are fixed to 100 ms, acknowledge P/brake/clearance/native controls, then Move once. Cancel sends no command. The default is Backrest. Each trial has a trace ID, complete typed cache samples, command/release results and ten seconds of read-only observation. Physical-control and native-preset markers label owner intervention without claiming its exact timing.

The installed native app's source uses signal 1 for forward/up, 2 for back/down and 0 on release. The owner confirmed one driver-backrest forward pulse and autonomous stop; the backrest cache advanced by one numeric unit while the other seat axes remained unchanged. Other axes, directions, durations, multi-axis loading, accuracy and repeated cancellation still need owner-operated validation. There is no claim of a guaranteed physical distance or hardware stop.

The optional comparison reads four mirror axes through typed VHAL feedback, named getters and both reviewed generic getter namespaces, for Native MyCar and Collector SDKs. SDK defaults and 127.5 sentinels are not saved coordinates. That comparison sends no write. The separate tilt trial maps left horizontal to actions 1/2, left vertical to 3/4, right horizontal to 5/6 and right vertical to 7/8, as declared by the SDK. The setting API routes to property 0x21403b74. It is distinct from fold/unfold. Release=0 is an unverified stop candidate: keep native controls ready, confirm physical movement/stop or mark intervention. All seven valid readings are required before a mirror trial. Owner confirmation records evidence only and never enables mirror preset loading.

Set up seat access explicitly grants missing reads and SETTING_SET for this app through the setup channel. It sends no seat command, enables no movement toggle and changes no recovery policy. Nothing in startup, update, readiness or Android user unlock starts a load. One process-owned motion session runs at a time; silent package replacement is excluded while motion owns that gate.

All trial and load events use the separate private report and the existing trusted Lab transfer. The retained report is bounded at 180,000 characters; the signature inventory and report are sent together within the existing 262,144-byte contract. Failed flushes, early-memory loss, rotation, sensitive-line omission and byte truncation remain explicit warnings. Pending memory cannot survive process death.

See NATIVE-SIGNAL-FINDINGS.md for evidence limits. Demo runs the same trial/coordinator/feedback engine using synthetic data with no OEM invocation. Emulator checks do not validate physical behavior.

The optional single-pulse trial can save an owner-confirmed numeric direction per axis and firmware. Stale, flat, coupled or unusually large changes are not accepted as direction evidence. This changes no preset coordinates, and the loader never learns/reverses direction automatically after an unexpected step.

November 2 owner feedback reports successful seat trials and eventual preset loading. Logs retain one full three-axis feedback match, four no-change aborts and two no-motion already-matched requests. This does not validate new 100–300 ms timing or any mirror action. The new loader removes the extra settling pause and uses conservative longer holds away from a target. It still stops on missing/stale progress; it does not blindly retry an unobserved movement.

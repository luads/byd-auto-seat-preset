Seat Presets 0.1.12 (versionCode 13), pre-alpha.

- Full Load preset flow replaces A-B-A calibration. Seat movement is off by default and requires explicit opt-in in Settings.
- Cards, floating panel, Android widget and child-lock shortcuts share one controller. P, applied parking brake, awake screen, compatible saved coordinates and the movement switch are checked before commands. Overlapping requests are dropped; requests expire, are never persisted, and never run from startup/update/home display.
- Optional child-lock shortcuts run only while enabled, awake and reporting P, in the existing accessibility service. Fresh baselines and invalid/gap resets prevent startup samples from triggering. No wake lock or wakeup alarm is added.
- The BYD dashboard's known SystemUI card surface no longer immediately hides the panel. Other activities, including the app drawer, remain excluded. Setup reuses already-granted permissions.
- Hold to save the current position. Edit > Adjust saved target permits an explicit saved percentage adjustment without moving until requested.

The typed fore/aft getter returned zero, but the readable float car property reported a coordinate. A fixed read-only fallback now extracts that property through the existing ADB identity, with no key generation or settings change. Cache timestamps remain observation metadata. Zero/unavailable axes are skipped, never driven to an endpoint. Re-save old zero-coordinate presets to capture fore/aft; the full load includes each axis only when both saved/current readings are usable. OEM getters are cache observations, not proof of fresh physical telemetry; command return is not proof of completion or interruption. Physical behavior must be checked by the owner at the native controls. No NFC identity selection is enabled.

Validation: 97 JVM tests per variant and debug/release lint/build checks passed. The stable-signed APK was installed in place on the owner car. Home/menu/Home visibility and a separate saved-position readback were exercised without sending movement. Existing favourites were preserved. A bounded getter-only cold-connection retry was added after the real OEM returned “not connected” immediately after reinstall. No setter retries occur. Actual motion and physical interruption remain owner tests; overnight and continuous-shortcut CPU/12V behavior remain unverified.

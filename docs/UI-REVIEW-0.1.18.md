# Structured seat trial review

| Before | After |
| --- | --- |
| Unsupported A/B/C geometry choices dominated the test. | The screen follows read, choose one native pulse, confirm, observe and optionally confirm numeric direction. |
| Large single-column controls pushed readback far below the action. | Controls and readback sit in two columns on the wide dashboard; narrower screens stack them. |
| Old read-only and movement trials competed in Settings. | One Seat trials entry owns optional checks. Read-only mirror route comparisons and explicit access setup remain inside it. |
| Trial output could expand into a long SDK dump. | The screen summarizes mirror comparisons; complete raw results stay in the private report. |
| No persistent action to cancel a multi-step load. | Stop is available in the main app and floating panel; another recognized child-lock double cancels an active load. |

The favourite cards and dark matte identity stay unchanged. Device screenshots remain local because preferences can contain personal driver labels.
